# PRODUCT_VISION.md — Drink Shop Management System (DSMS)

## Problem Statement

ร้านเครื่องดื่มขนาดเล็ก-กลางส่วนใหญ่จัดการต้นทุน สต็อก และยอดขายด้วยสมุด/Excel แยกกัน
ทำให้เจ้าของร้านไม่รู้กำไรที่แท้จริงแบบ real-time และตรวจสอบย้อนหลังยาก

## Vision

ระบบเดียวที่เชื่อมต้นทุนวัตถุดิบ → สูตร → เมนู → การขาย → กำไรจริง แบบอัตโนมัติและตรวจสอบได้

## Target Users & Value per Role

| Role     | ความต้องการหลัก                                                       |
| -------- | --------------------------------------------------------------------- |
| Owner    | เห็นกำไร-ขาดทุนแบบ real-time, ตรวจสอบย้อนหลังได้, ควบคุมสิทธิ์พนักงาน |
| Manager  | จัดการสต็อก/สูตร/เมนู, ดูรายงานประจำวัน/สัปดาห์                       |
| Cashier  | ขายหน้าร้านเร็ว ไม่ผิดพลาด ไม่ต้องเข้าใจ business logic เบื้องหลัง    |
| Employee | บันทึกสต็อกเข้า-ออก ตามสิทธิ์ที่ได้รับ                                |

## Non-Goals

- ไม่ใช่ระบบบัญชีเต็มรูปแบบ (ดู `PROJECT_SCOPE.md`)
- ไม่ใช่ระบบ POS สำหรับร้านอาหารเต็มรูปแบบ (ไม่มี table management/kitchen display ใน MVP)
- ไม่ใช่ระบบสำหรับเชนขนาดใหญ่ (multi-branch เป็น future phase เท่านั้น)
